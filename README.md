# Nishana_3D Pistol Range

**Live Play:** [https://saiqulmodi.github.io/Nishana_3D/](https://saiqulmodi.github.io/Nishana_3D/)

A browser-based 3D precision pistol target range built with **Three.js**, **Web Audio API**, and **Tailwind CSS**, featuring slide blowback recoil, red-dot holographic reflex optics, ejecting brass casings with metallic shell-ping audio, and three tournament target disciplines (**Stationary**, **Rail Move 1.25×**, and **Pendulum Arc 1.50×**).
